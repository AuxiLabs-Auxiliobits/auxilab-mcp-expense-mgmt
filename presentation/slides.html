The Problem

Enterprise expense approval is manual, slow, and catches compliance violations too late.

❌ Today's pain

  • Approval queues back up — managers lack context to prioritise
  • Finance teams manually cross-check receipts against policy documents
  • Violations found after reimbursement — recovery is costly
  • No audit trail — disputes can't be resolved
  • Multi-agency orgs have no agency-scoped isolation
  • LLMs used for decisions produce hallucinated policy citations

✅ Our solution

  • Deterministic intake — policy violations caught at submission, not after
  • Math decides; LLM advises — no numeric hallucinations
  • Multi-stage approval with segregation of duties enforced in code
  • Immutable audit log — every state change recorded
  • Full agency-scoped RBAC — managers see only their team
  • 60+ MCP tools — AI agents interact with the platform natively

What We Built

A full-stack enterprise expense platform: deterministic compliance engine, multi-role web portal, REST API, and an MCP server your AI agent can talk to directly.

⚙️

5 Deterministic Engine Tools

Policy checker, receipt parser, category classifier, duplicate detector, report summariser — pure Python, zero LLM required for core decisions.

🔌

MCP Server — 60+ Tools

Full API surface exposed to Claude Desktop or any MCP host. Employees and admins interact in natural language; every call is RBAC-enforced.

🔁

Multi-Stage Approval

Employee → Manager → AI Finance Approver → Finance Human. State machine enforces transitions; segregation of duties is code, not policy.

🏢

Agency-Scoped RBAC

5 roles. Managers see only their agency's sheets. Finance cannot override their own submissions. Admin manages users, not expenses.

🤖

In-App AI Assistant

Natural language routed deterministically to API calls. Every answer cites the rule applied — no hallucination, no guess.

☁️

Runs Offline or on Azure

SQLite + local providers for dev/demo. Swap to PostgreSQL + Azure Foundry + AI Search + Document Intelligence at config level.

✅ Security posture

  • RBAC enforced at API layer — client never trusted
  • Segregation of duties — coded, not policy
  • Immutable audit log — every transition recorded
  • Rate limiting (slowapi) + CORS + JWT crypto
  • Pluggable auth — DB now, Entra SSO at config flip

✅ LLM safety

  • Deterministic caps override LLM verdict
  • Every answer cites the rule it applied
  • Offline fallback — no LLM = route to human
  • Azure Content Safety + Prompt Shield hooks
  • No LLM has write access — humans confirm mutations
